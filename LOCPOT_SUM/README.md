# VASP_LOCPOT-sum

## Overview
This code reads a `LOCPOT` file generated by VASP, averages the 3D potential grid over the x-y plane for each z point, and writes the result to a new output file.

The output contains:

- position along the c direction
- plane-averaged LOCPOT value at each z point

The final output file is:

    LOCPOT_sum-c

---

## Required Files
Prepare the following files in the same directory:

- `LOCPOT`
- `POSCAR` or `CONTCAR`

## Notes
- `LOCPOT` is required.
- Either `POSCAR` or `CONTCAR` must exist.
- The program reads the lattice length along the c direction from `POSCAR` first.
- If `POSCAR` does not exist, it automatically tries `CONTCAR`.
- The result is written as a two-column text file.

---

## Compile
Compile the source code with:

    gcc VASP_LOCPOT-sum.c -lm -o locpot.x

You may change the executable name freely. For example:

    gcc VASP_LOCPOT-sum.c -lm -o mycode.x

---

## Usage
Run the executable in the directory containing `LOCPOT` and `POSCAR` (or `CONTCAR`):

    ./locpot.x

---

## Output
After execution, the following file is generated:

- `LOCPOT_sum-c`

Each line of the output file contains:

1. z position along the c axis
2. plane-averaged LOCPOT value at that z position

---

## What This Code Does
1. Reads the `LOCPOT` file
2. Determines the total number of atoms
3. Reads the 3D grid size (`NGX`, `NGY`, `NGZ`)
4. Extracts the original 3D grid data
5. Reads the lattice information from `POSCAR` or `CONTCAR`
6. Calculates the c-axis length
7. Averages the LOCPOT values over the x-y plane for each z grid point
8. Writes the z coordinate and averaged value to `LOCPOT_sum-c`

---

## Example Output
The output format is similar to:

    z_position    averaged_value

For example:

    0.000000    1.23456789012E+00
    0.150000    1.21000000000E+00
    0.300000    1.18000000000E+00
