# VASP_PARCHG-exp

## Overview
This code reads a `PARCHG` file generated by VASP, applies an exponential transformation to the 3D grid values, and writes the result to a new output file.

The transformation applied to each grid value is:

    new_value = 10000^(original_value) - 1

The final output file is:

    PARCHG_log

---

## Required Files
Prepare the following files in the same directory:

- `PARCHG`
- `POSCAR`

## Notes
- The code reads structural and grid information from `PARCHG`.
- `POSCAR` is used when generating the final output file.
- The result is written in a VASP-like format.

---

## Compile
Compile the source code with:

    gcc VASP_PARCHG-exp.c -lm -o parchg_exp.x

You may change the executable name freely. For example:

    gcc VASP_PARCHG-exp.c -lm -o mycode.x

---

## Usage
Run the executable in the directory containing `PARCHG` and `POSCAR`:

    ./parchg_exp.x

---

## Output
After execution, the following file is generated:

- `PARCHG_log`

This file contains:

- structure/header information
- transformed 3D grid data

Temporary files generated during execution are removed automatically.

---

## What This Code Does
1. Reads the `PARCHG` file
2. Determines the total number of atoms
3. Reads the 3D grid size (`NGX`, `NGY`, `NGZ`)
4. Extracts the original 3D grid data
5. Applies the exponential transformation to each grid value:

       10000^x - 1

6. Writes the transformed data to `PARCHG_log`
